Don't\n- Store plaintext passwords\n- Log sensitive data (passwords, tokens, secrets)\n- Skip JWT expiry validation\n- Allow unlimited login attempts\n- Use weak bcrypt rounds (< 10)\n- Allow all CORS origins\n- Expose database errors to users\n- Skip input sanitization\n\n### ✅ Do\n- Hash passwords with bcrypt 12+ rounds\n- Log only non-sensitive information (email, userId, action)\n- Validate JWT (signature, expiry, issuer, audience, type)\n- Limit login to 5 attempts per 15 minutes\n- Use CORS restricted to your frontend URL\n- Return generic error messages in production\n- Sanitize all user input\n\n---\n\n## Quick Reference\n\n### Commands\n\n```bash\n# Install dependencies\nnpm install bcrypt jsonwebtoken validator express-rate-limit\n\n# Generate secrets\nnode -e
